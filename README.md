# Week 2 – Day 2: JSON Prompting for Tamil Visuals

## Project Overview
This project demonstrates structured JSON prompting to generate culturally inspired visuals representing the 11th-century Chola dynasty in Tamil Nadu.

The storyline follows a victorious Chola king returning to his palace after winning a war.

## Tools Used
- ChatGPT – Image generation
- Gemini – Video generation
- JSON – Structured prompt design
- Visual Studio Code – Project development

## Project Deliverables

### Image 1 – Base Template
Original Chola victory procession.

### Image 2 – Golden Hour Variation
Changed the `setting.time_of_day` field.

### Image 3 – Close-up Variation
Changed the `camera.shot` field.

### Video – 5 Seconds
A cinematic representation of the Chola victory procession with motion elements.

## Learning Outcomes
- Understanding structured JSON prompting.
- Creating reusable prompt templates.
- Controlling image generation through individual JSON fields.
- Experimenting with camera and lighting variations.
- Extending image prompts with motion parameters for video generation.

## Conclusion
This exercise demonstrates how structured JSON prompts provide better control, consistency and repeatability when generating AI-powered Tamil historical visuals.
